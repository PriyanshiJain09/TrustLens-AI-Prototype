# TrustLens 🎯

**Find the right opportunities. Avoid the wrong ones.**

## Description
TrustLens is an AI-powered student opportunity intelligence platform that discovers internships, jobs, hackathons, scholarships and fellowships, matches them to students' profiles and flags potentially fraudulent listings before they apply.

## Key Features
- 🔍 **Smart Discovery:** Discover opportunities from multiple sources using TinyFish-powered web crawling.
- 🎯 **Personalized Matching:** Get recommendations based on skills, interests, eligibility, and career goals.
- 🛡️ **Fraud Detection:** Identify suspicious recruiters, mismatched domains, fake listings, and payment scams.
- 📊 **AI-Powered Insights:** Understand match scores, missing skills, and opportunity risk indicators.
- 📅 **Deadline Tracking:** Save opportunities and manage application deadlines.

## Tech Stack
React, TypeScript, Vite, Tailwind CSS, and TinyFish-powered web intelligence.

## Vision
To make opportunity discovery smarter, safer, and more accessible for every student.
